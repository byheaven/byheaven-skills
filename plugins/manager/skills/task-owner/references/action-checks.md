# Action checks

These reminders route to the existing authorities; they do not judge compliance.

## Session

Apply the task-owner role only when this session holds a task's Goal; keep any coordinator, project-driver or leaf assignment the deployment gave. Read its checklist before delivery.

## Publish

For a push or PR change, apply repository integration to the current candidate, required checks, review dispositions and publication authority. A published candidate is not a completed merge.

## Merge

Apply the repository's controlled merge entry and the task's current integration evidence. Close the applicable gates on the exact candidate; a reminder supplies no gate receipt.

## Dispatch

Apply Production's directive contract and the deployment's model routing; record model, effort and source in the directive. Review runs under Verification carrier. Preserve a result route that resumes the owner.

## Rules

Agent-facing rule text: write it with `writing-for-agents`, carry its self-check, and take the deployment's one-round review before it lands.

## Finish

Apply the role's records and report contract and Evidence's predicate closure; separate delivered results from pending evidence. Route questions as the deployment says, then end the turn.
