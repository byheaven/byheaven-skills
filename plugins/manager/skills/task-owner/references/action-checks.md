# Action checks

These reminders route to the existing authorities; they do not judge compliance.

## Session

Apply the supplied task-owner role only when this session holds a task's Goal. Keep any deployment-assigned coordinator, project driver or bounded-leaf assignment. Read the role's method checklist before delivery.

## Publish

For a push or PR change, apply repository integration to the current candidate, required checks, review dispositions and publication authority. A published candidate is not a completed merge.

## Merge

Apply the repository's controlled merge entry and the task's current integration evidence. Close the applicable gates on the exact candidate; a reminder supplies no gate receipt.

## Dispatch

Apply Production's directive contract and the deployment's Model routing authority. The dispatcher records model, effort and authorized source; this reminder selects none. For review, the owner uses Verification carrier directly, with its exact-state, read-only and result guards. Preserve a result route that resumes the owner.

## Finish

Apply the role's records and report contract and Evidence's predicate closure. Separate newly delivered results from pending evidence. Return questions through the deployment's question route and finish the turn; preserve recorded sessions for rework.
