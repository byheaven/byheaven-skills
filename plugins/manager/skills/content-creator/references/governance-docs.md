# Governance Documents

Vision and principles documents. Also load the canonical document-architecture rules, from the byheaven vault at `AI/rules/document-architecture-rules`, or from the bundled mirror at `references/_vault/document-architecture-rules.md` when you cannot reach the vault. They own Vision qualification, placement and links, and body and change discipline.

The user settled this structure for the main text:

- A Vision is a program, not a statute. The main text states each judgment and the cost it accepts ("X for Y"); conditions, exceptions, boundaries, examples, and qualifiers added for rigor go to the reference notes.
- Unproven judgments are grouped as hypotheses under test.
