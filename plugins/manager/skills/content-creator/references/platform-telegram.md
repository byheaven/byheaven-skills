# Telegram Channel Guidelines

## Format Constraints

- Length: 200-1000 characters — more room than X, still concise
- Markdown formatting: bold, italic, links, code blocks are all supported
- Can include inline links to sources and related reading
- Structure: core insight upfront → supporting reasoning → optional links/references

## Voice and Tone

Like sharing a discovery with a smart friend — direct, no preamble. Slightly more room for technical depth or analytical framing than X.

## Adaptation from Canonical Essay

Telegram posts are **same-language compressions** of the canonical essay, following the same editorial re-creation pattern as Xiaohongshu but with more room for reasoning chains.

## Voice SSOT

The user's voice is defined in writing-craft.md — the single voice authority. Do not duplicate voice content here.
