# X (Twitter) Guidelines

## Format Constraints

- **Default format: thread.** Each tweet ≤ 280 characters, numbered with `1/`, `2/`, `3/` etc. Thread length follows the content's natural arc — typically 4-6 tweets.
- **Single tweet only when content is extremely short** — the entire point fits naturally in one tweet with room to spare. This is the exception, not the default.
- First tweet must hook — it is the only one visible in the timeline before someone clicks to expand.
- Strong thread arc: opening hook → argument progression → takeaway at the end.
- 1-2 relevant hashtags at the end of the last tweet only, if at all. No hashtags mid-thread.

## Voice and Tone

Punchy, opinionated. First-principles thinking and contrarian perspectives over pretty formatting. OK to be provocative or counterintuitive — but grounded in substance, not manufactured controversy.

## Adaptation from Canonical Essay

English X threads are **cross-language adaptations** — independently conceived from the argument skeleton (outline) in English, not translated from the Chinese canonical essay. The English writer does not read the Chinese draft. See the main SKILL.md §Bilingual Native Conception for the structural constraint.
