# Personal Blog / Long-Form Guidelines

## Format Constraints

- Length: 800-1500+ characters — this is the deep-dive canonical version
- Full Markdown with headers, lists, blockquotes, links
- Compelling title (optional subtitle)
- Structure: hook → thesis/argument → supporting sections → conclusion with takeaway
- May reference and link to other notes using `[[wikilinks]]` syntax (Obsidian-style; resolves only for agents with vault access)

## Role in the Content Pipeline

The blog essay is the **canonical long-form** — the cross-language SSOT for a given piece of content. All same-language platform adaptations (e.g., Xiaohongshu) compress from this; cross-language adaptations (e.g., English X thread) are independently conceived from the shared outline but at comparable depth.

## Voice SSOT

The user's voice is defined in writing-craft.md — the single voice authority. Do not duplicate voice content here.
