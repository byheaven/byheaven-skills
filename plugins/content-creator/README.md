# content-creator

Claude Code plugin: draft any content with the user as the assumed author under a single mandatory voice system.

## What it does

- **Public writing** — X/Twitter, Xiaohongshu, blog essays, Telegram posts, plus platform-specific adaptations of approved material. Each language is natively conceived (never translated); Chinese and English drafts are produced independently.
- **Voice system** — `references/writing-craft.md` is the single authoritative voice definition: voice target, Author × Reader, public voice gate, Chinese hard rules, and English long-form rules.
- **Governance documents** — `references/governance-docs.md` carries the register for Vision, principles, rules, and decision records, with the canonical document-architecture rules bundled under `references/_vault/` so the skill runs fully self-contained.

Invocation is mandatory before drafting begins; drafts are never produced from memory or habit.

## Layout

```
plugins/content-creator/
├── .claude-plugin/plugin.json
├── CHANGELOG.md
├── LICENSE
├── README.md
└── skills/content-creator/
    ├── SKILL.md
    └── references/
        ├── writing-craft.md
        ├── governance-docs.md
        ├── platform-x.md
        ├── platform-xhs.md
        ├── platform-blog.md
        ├── platform-telegram.md
        ├── freshness.md
        ├── anti-perfectionism.md
        ├── image-generation.md
        └── _vault/
            └── document-architecture-rules.md   # mirror — do not hand-edit
```

`_vault/` holds a mirror of the canonical rule file, regenerated by `scripts/publish-content-creator.sh`. The skill never depends on files outside the plugin directory.
