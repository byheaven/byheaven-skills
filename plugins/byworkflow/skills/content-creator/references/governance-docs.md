# Governance Documents

Vision and principles documents. When the project or workspace you write in defines its own document rules, such as where documents live, how they link, and what qualifies a Vision, those rules govern placement, links, and qualification. They load with that workspace's own instructions.

Structure the main text this way:

- A Vision is a program, not a statute. The main text states each judgment and the cost it accepts ("X for Y"); conditions, exceptions, boundaries, examples, and qualifiers added for rigor go to the reference notes.
- Unproven judgments are grouped as hypotheses under test.
